# 《盤勢・眾生》V5 全球競品求同存異

_研究更新：2026-07-23｜只使用官方產品頁、官方商店頁、官方文件與原始研究_

## 研究判決

《盤勢・眾生》不該被做成「帶 AI 小人的股票模擬器」，也不是「接了台股資料的 AI Town」。

較準確的類別是：

> 真實台股驅動、持續運行的 AI 角色實境世界。

本輪樣本沒有找到一個產品同時具備以下組合；這是研究觀察，不是「全球首創」宣稱：

- 真實市場事件是全世界共同時間軸，不由模型編造。
- 一群成年虛構角色住在同一條不可重跑的公共正史。
- 性格、命盤、記憶、情緒與關係持續改變人物行為。
- 紙上持股與績效是人物後果，不是玩家或模型排行榜。
- 玄學影響人物如何注意、解讀與承受，不負責預測漲跌。
- 使用者先當觀眾，只能放入有限故事條件，不能遙控人物。

競爭優勢不在單一模型。模型會換；多年累積的共同事件、角色記憶、關係、紙上交易、改口與可稽核故事鏈才是產品資產。

## 六個相鄰市場

### 1. AI 代理世界

樣本：

- [Generative Agents](https://arxiv.org/abs/2304.03442)
- [AI Town](https://github.com/a16z-infra/ai-town)
- [Project Sid](https://arxiv.org/abs/2411.00114)
- [WorldOS](https://worldos.cc/)

共同呈現：

- 從俯視世界看很多角色生活。
- 記憶、反思、計畫和社交傳播讓群體事件長出來。
- 事件日誌和向量記憶支撐角色延續。
- 部分產品允許建立、重混、回溯或直接改寫世界。

V5 借：

- 公共世界 → 跟拍 → 單角人生誌的觀看距離。
- 角色在使用者離線後繼續生活。
- 記憶、關係與未完事件跨日延續。
- append-only 正史支撐故事，前台不傾倒 agent log。

V5 不借：

- 無限平行世界、回溯重選和重混正史。
- 一句 prompt 改掉人格、記憶或結果。
- 把會走路、會聊天當成角色已經成立。
- 為了展示模型而讓所有人不停說話。

### 2. 人生模擬與故事生成

樣本：

- [The Sims 4](https://www.ea.com/en/games/the-sims/the-sims-4/new-player-hub/base-game)
- [The Sims Gallery](https://www.ea.com/en/games/the-sims/the-sims-4/new-player-hub/the-gallery)
- [inZOI](https://www.krafton.com/en/games/inzoi/)
- [AI Dungeon](https://help.aidungeon.com/memberships-benefits)
- [Showrunner](https://www.showrunner.xyz/)

共同呈現：

- 建立角色本身是一項承諾。
- 人格、情緒、關係和長期存檔讓小事件有重量。
- 付費常落在世界內容包、上下文、記憶深度或創作能力。
- 使用者多半能直接控制、重開分支或重寫角色。

V5 借：

- 人格必須改變注意、解讀、情緒和選擇，不能只在角色卡上。
- 每個角色有長期故事弧與可追蹤關係。
- 場景和人物片段能分享，也能回到完整正史。
- 引介角色要有不可重抽的承諾感。

V5 不借：

- 讓使用者控制每一個動作。
- 任意分支、重抽、重寫結果。
- 角色資產包、稀有度和抽卡商城。
- 要求使用者同時當導演、編劇、操盤手和資料管理員。

### 3. AI 陪伴與長期記憶

樣本：

- [Character.AI](https://support.character.ai/hc/en-us/articles/41760067000475-Community-Update-September-2025)
- [Nomi](https://nomi.ai/nomi-knowledge/nomi-101-a-beginners-guide-to-getting-started-with-your-ai-companion/)
- [Kindroid](https://kindroid.ai/docs/article/memory/)
- [Replika](https://help.replika.com/hc/en-us/articles/4411154990605-Is-the-chat-history-infinite)

共同呈現：

- 短、中、長期記憶維持「還是同一個人」。
- 主動訊息、日誌、群聊和語音製造關係連續性。
- 付費多半增加記憶、模型、主動互動、角色數或免廣告。
- 使用者可以編輯、固定或重開部分記憶與對話。

V5 借：

- 角色記得承諾、羞恥、虧損、嘴硬、被背叛和曾看錯的資料。
- `A → B` 與 `B → A` 是兩個方向，不是同一好感值。
- 通知來自未完人物故事，不只等使用者先開口。
- 深層檔案顯示記憶來源、可信度和後來修正。

V5 不借：

- 私密、排他的「他只屬於你」。
- 付費購買角色感情或服從。
- 角色無條件迎合、隨叫隨到。
- 模型記錯後靜默覆蓋舊人生。
- 把 raw chain-of-thought 冒充人物真正內心。

### 4. 股票模擬

樣本：

- [TradingView Paper Trading](https://www.tradingview.com/support/solutions/43000516466-paper-trading-main-functionality/)
- [TradingView Demo Features](https://www.tradingview.com/support/solutions/43000754966-demo-features-on-tradingview/)
- [eToro Demo Account](https://www.etoro.com/trading/demo-account/)
- [The Stock Market Game](https://www.stockmarketgame.org/tour/)

共同呈現：

- 使用者直接選資產、下單、看持股、損益、績效與排名。
- 虛擬本金、成交規則、價格和交易歷史清楚。
- 回訪理由通常是行情、操作和相對績效。

V5 只借資料可信度：

- 明確標示虛擬本金和紙上模擬。
- 保存 intent、成交、價格、數量、費用、已實現與未實現損益。
- 顯示 `as_of`、交易日狀態、資料來源和修正。
- 回看角色當時真正接觸過的資訊。

V5 不借：

- 全域績效榜、每週冠軍、最佳角色或最佳模型。
- 一鍵複製高績效人物。
- 用紙上結果導向真實下單。
- 依報酬率排序首頁。
- 把賺錢當作角色智力與價值。

V5 把績效放進「承擔紀錄」：它回答這個人為自己的判斷付出什麼，不回答現在該跟誰買。

### 5. 金融占星

樣本：

- [AstroApp Financial](https://astroapp.com/en/main-features-17/financial-astrology)
- [Fortunara](https://fortunara.app/)
- [Ask Lucky Stock](https://play.google.com/store/apps/details?id=com.ask.stock)

共同呈現：

- 把行情、星象、公司或首次交易命盤、月相和日曆疊在一起。
- 以固定儀式、分數或訊號吸引每日回訪。
- 有些產品直接產生 `BUY`／`SELL`／`HOLD`。

V5 借：

- 星象日曆、節律、相位和市場事件的視覺對照。
- 少量象徵語言替人物建立私人重量。
- 深層命盤能回到具體人生事件。

V5 不借：

- 星象直接觸發買進、賣出或持有。
- 命定漲跌、宇宙選股、勝率或入場時點。
- 公司命盤或角色出生資料成為價格因果證據。
- 用星座、血型和四軸刻板產生固定台詞。

V5 每次都分開：

1. 真實市場發生什麼。
2. 角色怎麼解讀。
3. 角色後來承擔什麼。

### 6. 短影音與連載觀看

樣本：

- [ReelShort](https://apps.apple.com/us/app/reelshort-stream-drama-tv/id1636235979)
- [Character.AI Streams](https://labs.character.ai/streams)
- [Showrunner](https://www.showrunner.xyz/)
- [Chapters](https://apps.apple.com/us/app/chapters-interactive-stories/id1277029359)
- [Viu Shorts](https://www.pccw.com/assets/Common/files/press-release/2026/Jan/Press%20release_Viu%20unveils_Viu_Shorts_EN.pdf)

共同呈現：

- 一分鐘完成一個小事件。
- 固定角色、每日更新、未完關係和下一集拉回訪。
- 影片可獨立分享，也能導回原始集數。
- 多數使用者先觀看，少數人再創作。

V5 借：

- 0–3 秒：人物眼前出了什麼事。
- 3–15 秒：他相信什麼，或誰影響了他。
- 15–40 秒：人物行動、猶豫或嘴硬不動。
- 40–55 秒：交代一個完整人物後果。
- 55–60 秒：留人物或關係問題，不留股價吊胃口。

分類固定為：

- 市場日記
- 人物近況
- 事件後續
- 關係失控
- 嘴硬現場

每支影片導回該角色、日期和人生誌章節，不導回股票搜尋。

V5 不借：

- 每幾十秒付一次幣。
- 在結果前插廣告，逼人付費才知道一幕的結局。
- 付費才能救角色或做「善良選擇」。
- 熱門股、必看標的和買賣暗示。
- 為了鉤子扭曲真實事件。

## 求同後的產品迴圈

```text
真實市場事件
→ 不同角色接觸到不同片段
→ 性格、記憶、關係與象徵框架改變解讀
→ 人物行動或不行動
→ 紙上持股、情緒、生活與關係留下後果
→ 系統選出值得看的場景
→ 公共世界／跟拍／人生誌／深層檔案
→ 使用者追蹤、分享或有限編導
→ 有限編導成為下一段可能被忽略的世界條件
```

首頁故事排序依序看：

1. 未完人物線的延續性。
2. 信念與行為的矛盾。
3. 關係是否改變。
4. 市場事件對人生的後果。
5. 使用者已追蹤角色的更新。

紙上報酬、模型與「菜度」不能成為主要排序因素。

## 商業模式的共同答案

跨類別最一致的做法：

- 免費先看，先讓人喜歡一名角色。
- 讓使用者隔天找回同一人，不每天換主角。
- 用記憶、關係與未完事件製造回訪。
- 付費買更深的連續性、有限作者權和免廣告，不買結果。
- 分享一段精確人物場景，讓新觀眾直接看懂。

V5 因此採：

- 公共世界永久免費。
- 帳號前 30 日免廣告，之後只在完整章節之間顯示長版廣告。
- Pro 無廣告、完整人生、每週引介五名居民、每週三次有限編導。
- 退訂後人物繼續公開生活；原引介關係和私人工具轉為唯讀，復訂後恢復。
- 不做代幣、抽卡、付費重抽、模型勝率 tier 或角色贖回。

## V5 定價

正式版先只設一個 Pro：

- 月繳 NT$329。
- 年繳 NT$2,790，約比連續月繳少 29%。
- 顯示含稅總價；App Store 使用最接近的合法價格級距，權益不變。
- 不設週繳、終身買斷、代幣、引介加購或高勝率模型包。
- 帳號前 30 日免廣告不是 Pro 試用，不要求先綁卡。
- 封測使用 `beta_full_access`，不顯示真實扣款。

價格略高於台灣 Character.AI 與 Co–Star 的月費，低於 Nomi 的重度一對一陪伴。V5 提供長線共同世界、角色記憶和真實市場事件，但不提供全天私密陪伴、大量語音或投資工具，不用 NT$490 以上測第一版。

### 經濟驗收

正式扣款前先用 30 日封測的實際用量計算：

- 模型、圖像、語音、資料、儲存、CDN、商店與支付變動成本合計，不超過淨收入 35%。
- p75 Pro 使用者每週引介五人、使用三次有限編導時，仍能守住成本線。
- Free 廣告收入不預先寫進獲利預測；只用實際 fill rate、完成率和淨收入。
- 超過成本線時，先用 activity tier、共享抽取、batch、cache 和靜態 fallback 修正；不能刪角色、藏虧損、賣行情優勢或降低免費故事完整度。
- 超過成本線就阻擋 M5；降低基礎設施與供應成本後，仍以 NT$329／NT$2,790 和每週 5＋3 權益重驗。
