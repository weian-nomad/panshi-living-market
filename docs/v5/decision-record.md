# ADR-PRODUCT-005｜跟拍是鏡頭，不是完整產品

_Accepted 2026-07-23_

## 決策

《盤勢・眾生》的正式產品結構是：

```text
公共世界
→ 跟拍
→ 角色近景
→ 角色人生誌
→ 深層檔案
```

公共世界負責讓人遇見角色；跟拍負責把觀眾的注意力變成鏡頭；人生誌和深層檔案負責讓一個人值得長期追。

角色的紙上持股、損益、交易、原始理由、改口、記憶、關係、命盤與生平必須存在。這些資料不是首頁控制台，也不拿來排出最強角色；它們是人物確實承擔過後果的證據。

## 為什麼重做

V4 原本是一個十分鐘跟拍研究。為了讓原型專心驗證鏡頭，它暫時拿掉角色檔案、持股和績效。後來這個測試範圍被誤寫成永久產品禁令，造成三個問題：

1. 觀眾能靠近角色，卻不能真的走進他的人生。
2. 人物的市場判斷沒有可核對代價，故事變成漂亮但無重量的片段。
3. 可愛群像和角色資料被一起刪掉，畫面退化成冷靜研究展示。

問題不在角色資料本身，而在資料曾被放錯層級。正確修法是重新安排資訊距離，不是刪掉深度。

## 保留 V4 的部分

- 公共世界先於角色資料。
- 跟拍時有視野代價，不能同時監看所有人。
- 人物不接受交易指令、自由 prompt 或重抽。
- 市場事實、人物說法與象徵解讀分開。
- 沒有全域績效、模型能力或「菜度」排行。
- 離線期間世界繼續，既成結果不回滾。

## 撤銷 V4 的部分

- 「角色詳情永遠不出現」。
- 「持股與績效永遠不出現」。
- 「十分鐘跟拍原型就是產品終局」。
- 「冷色研究場景就是正式視覺」。
- 「資訊少等於風險低」。

## 後續約束

任何新原型都可以縮小角色數、場景數或資料期間，但不能用研究方便重新定義正式產品：

- 高保真首批可先用 16 名居民；封測以 50 名完整種子居民開場。Authoring 只開放連續 30 個日曆日、最多六個相交 quota windows，60 名測試者用滿時必須 qualification 到 1,850 名；之後停止新增人口，世界與完整觀看繼續到至少第 30 個完成交易日。
- 可以先做一名角色的完整垂直切片；資料形狀仍要是最終事件、帳本與人生誌。
- 可以關閉金流與廣告 adapter；Free、Pro、失訂和恢復狀態仍要完整。
- 可以使用結構化備援文案；不能因模型失敗改寫人物人生。

未來若要移除人生誌、隱藏紙上虧損、恢復全域績效榜，或把跟拍再次升成唯一導航，必須新建產品 ADR，附使用者證據並明確推翻本決策。不能由單一畫面、風險說明或工程便利暗中改回去。
