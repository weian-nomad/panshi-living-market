# 《盤勢・眾生》視覺與動態系統

_V5.0｜2026-07-23｜供 Figma、ImageGen、Web、App 與短影音共用_

## 視覺判決

畫面要讓人先想靠近小人，再想讀資料。

V4 的冷靜研究場景不足以承接最終產品。V5 恢復可愛、精緻的 2.5D 群像與高密度角色人生誌，也保留共享空間的生命感。首頁不能變回金融 Dashboard；角色深頁則不能再害怕資訊。

視覺氣質固定為：

- 可愛，但一眼看得出是成年人。
- 溫暖，但生活會留下疲憊、狼狽與磨損。
- 神祕，但市場時間與事實來源很清楚。
- 資訊密度高，但每一屏只回答一個人物問題。
- 有幽默感，但不把失敗角色做成被嘲笑的迷因。

### Production token source

本檔是角色比例、場景密度與鏡頭時間的唯一 production source。其他規格只能引用，不另設數值：

| Token | 固定值 | 使用規則 |
| --- | --- | --- |
| `character.proportion.heads` | 3.5–4.5 頭身 | 所有角色仍須明確為成年人 |
| `world.residents.high_detail` | 12–16 | 同一 viewport 可辨識、可跟拍的高細節居民 |
| `world.residents.edge_silhouette` | 0–4 | 只在遠景邊緣出現，不承擔文字與精細表情 |
| `world.residents.total_max` | 20 | 高細節與邊緣剪影合計上限 |
| `world.clusters.natural` | 2–4 | 同一 viewport 的自然聚落數，不畫成卡片欄 |
| `motion.world_breath` | 8–12 s | 低幅循環；角色沒有事件時不做誇張 idle |
| `gesture.follow_hold` | 180 ms | 長按成立跟拍；人生誌不綁長按功能 |
| `camera.follow_in` | 280–420 ms | 依畫面距離取值；reduced motion 不使用縮放 |
| `camera.follow_subject_height` | 38% | 跟拍人物約占場景高度；窄螢幕仍保留環境 |
| `camera.follow_handoff` | 240 ms | 拖向注意對象後交接鏡頭 |
| `camera.follow_release_hold` | 800 ms | 放開後保留當前人物，再回全景 |
| `camera.closeup_cta_persist` | 2 s | 回全景後保留 `再靠近一點` 入口 |
| `motion.closeup_action_lead` | 600–900 ms | 近景先讓動作成立，再出人物文字 |
| `transition.sprite_to_closeup` | 360–480 ms | 從世界 sprite 走近同一張臉 |
| `transition.enter_journal` | 600–900 ms | 可中途取消，不能遮住資料狀態 |
| `transition.outcome_reveal` | 160–240 ms | 先人物事件，後顯示數字節點 |
| `transition.introduction_success_max` | 1.8 s | 只確認正式入場，不使用抽卡慶祝 |
| `motion.market_signal_in_max` | 400 ms | 冷色訊號只表示新事實抵達 |
| `motion.reduced_fade_max` | 120 ms | 以淡入、描邊與狀態文字替代空間動態 |

Figma variable、Web motion token、App animation constant、Remotion 與測試 fixture 都由這張表生成。若要調整，先升版本並同步所有消費端，不能在個別畫面補一個更順眼的數字。

## 參考圖留下什麼

使用者提供的角色介面參考保留以下結構：

- 左側可快速找到自己的居民。
- 中央以一名角色、生活空間與外在人設為主。
- 人格、命盤、內心、證據、持股、關係與歷史都能在同一個角色脈絡裡展開。
- 深墨、舊紙、銅色細線與高密度資料共同存在。
- 數字不是獨立報表；它與故事、時間和人物肖像相鄰。

需要修正的地方：

- 首屏不能同時攤開所有圖表。
- 人格數值不能只是一張雷達圖。
- 持股與績效不能和人物矛盾脫節。
- 導覽要從公共世界自然進入角色，不以「我的小人」當唯一首頁。
- 手機版不能把桌面版縮小；它要改成有節奏的直向人生誌。

## 五層畫面

### 公共世界

一個可探索的 2.5D 街區。首批地點固定為開盤廳、研究室、咖啡店、住家、車站與夜間屋頂。

首頁居民密度由 `world.residents.high_detail`、`world.residents.edge_silhouette` 與 `world.residents.total_max` 決定。剪影不承擔台詞、精細表情或跟拍入口。辨識依靠輪廓、髮型、服裝色、步態、常用物件與聲音。市場先改變環境：牆面脈衝、手機震動、電視字幕、人群轉頭或一份公告進場。

角色有三種遠距狀態：

| 狀態 | 畫面 |
| --- | --- |
| 日常 | 小幅呼吸、工作、走動與關係距離 |
| 被事件打斷 | 先動眼神與物件，再改姿勢與位置 |
| 正在掩飾 | 嘴上繼續原動作，身體卻偷看、停頓或避開某人 |

首頁沒有全員卡牆、排行、資產表或常駐 K 線。

### 跟拍與角色近景

按住居民後，鏡頭靠近到能看見表情、手部與桌上物件。跟拍時保留場景邊緣，讓觀眾知道其他人仍在生活。

近景只顯示：

- 姓名與此刻所在。
- 一句已通過可見性政策的不可變對外原話；沒有 artifact 就不補一句。
- 一個可觀察動作。
- 一個正在注意的人或物件。
- 「走進他的人生」。

不要在鏡頭上浮滿數值。需要理解背景時，使用者主動進入人生誌。

### 角色人生誌

人生誌像一份會繼續長大的角色雜誌，不像交易終端。

桌面版使用不對稱三欄：

1. 左欄是日期、近期章節與未讀變化。
2. 中欄是肖像、生活空間、當下矛盾與主事件。
3. 右欄只放與這一幕直接相關的關係、記憶、命盤主題與紙上代價摘要。

第一個 viewport 最多有一個主數字。其餘資料沿 canonical 時序往下；需要完整紀錄時進深層檔案。

人生誌沒有「承擔、關係、命盤、記憶、一生」七分頁。它只擁有：

- 今日與日期章節。
- 角色當時的可公開說法與後來改口。
- 這一事件直接相關的一項紙上或關係後果摘要。
- 回到當時場景與打開完整人生檔案的入口。

完整持股、人生曲線、交易、錯過、關係、命盤、性格、記憶與生平，只能由 `/archive/*` 擁有。人生誌可引用摘要卡，不能建立第二份可排序或可篩選的完整資料。

手機版依閱讀順序排列：

```text
肖像與此刻
→ 他原本怎麼說
→ 剛做的事
→ 紙上代價
→ 誰影響了他
→ 哪段記憶被碰到
→ 打開完整人生檔案
```

### 深層檔案

深層檔案可以有高資訊密度，但版面仍以一個事件為錨。

固定索引與 route：

- 模擬紀錄 `/archive/paper`
- 關係 `/archive/relations`
- 本命盤 `/archive/chart`
- 性格與習慣 `/archive/traits`
- 記憶 `/archive/memories`
- 生平 `/archive/life`

每個檔案頁固定保留：

- 目前閱讀的角色。
- 事件時間與資料截至時間。
- `truth_class` 文字與圖形標記。
- 回到故事章節的路徑。
- 資料修正、缺漏或作廢狀態。

表格與圖表不能自成死路。點選一筆交易、記憶或關係變化，會打開當時的場景、說法與後果。

### 分享與短影音

分享卡先有角色表情與一句前後矛盾，再放數字。

9:16 影片固定三拍：

1. 他昨天怎麼說。
2. 今天做了什麼。
3. 市場或關係讓他付出什麼。

片尾回到角色人生誌，不導向股票搜尋。

## 可愛小人的造型

角色比例使用 `character.proportion.heads`。頭部足以承載表情，但肩頸、手掌、服裝與步態必須保有成人比例。

每位角色需要：

- 一個遠距輪廓。
- 一組固定髮型、服裝主色和日常物件。
- 8 個表情 anchor：平靜、逞強、慌張、心虛、嫉妒、後悔、鬆動、認錯。
- 6 個身體 anchor：專注、偷看、僵住、退避、追出去、裝沒事。
- 3 種生活磨損狀態：睡眠不足、連續受挫、短暫恢復。
- 一個只屬於他的反覆小動作。

可愛不能靠幼兒化完成。禁止奶嘴比例、嬰兒肢體、過度圓亮眼睛、統一無齡漂亮臉與抽卡式性感姿勢。

人物差異包含年齡、體型、膚色、職業留下的姿勢、生活痕跡與衣物使用感。生成圖不能把所有人修成同一張臉。

## 「韭菜樣」的視覺語法

錯誤先透過行為被看見，再由文字補上。

| 行為模式 | 遠景與近景 | 人生誌 |
| --- | --- | --- |
| FOMO 追價 | 原本離螢幕很遠，價格連續變動後越靠越近 | 「他昨天說不追，今天在第 4 次抬頭後出手」 |
| 凹單 | 把退出條件便條壓到帳本下，反覆重開同一頁 | 原始計畫與現在說法並排 |
| 嘴硬 | 對外語氣穩定，手指卻持續敲桌或關掉對話 | 「他說沒受影響／之後避開了提醒他的人」 |
| 怪別人 | 結算後先看向某人，不看自己的帳本 | 關係變化與責任轉移時間線 |
| 過度自信 | 連續獲利後步幅、音量與曝險一起增大 | 人生曲線標記「開始省略反證」 |
| 認錯 | 關掉行情、拿回原始筆記、主動靠近被忽略的人 | 原話、修正與關係修復同屏 |

禁止「韭菜 +1」「理性 −8」或頭上冒出羞辱標籤。幽默來自觀眾認得他的自我矛盾。

## 持股與績效

市場數字使用固定網格，角色解釋使用紙頁。兩者不能混成一種字體或顏色。

角色深頁的持股主卡固定順序：

1. 人物動詞：「他還在撐」「她追進去了」「他終於減碼」。
2. 資料截至時間；盤中固定寫「截至前一交易日收盤」。
3. 持有數量、成本、現值、曝險與天數。
4. 已實現或未實現損益。
5. 原始理由與退出條件。
6. 現在說法。
7. 關係、記憶與資料節點。

「她追進去了」「他終於減碼」這類同日 ticker-specific 動詞只出現在盤後 finality 通過的回顧。盤中主卡只能用前一交易日已公開狀態，例如「他還抱著昨天的部位」；數字、人物動詞、分享卡與動態字幕共用同一個 `as_of` fence。

人生曲線是紙上總資產曲線，但圖上先標人物事件：

- 第一次追高。
- 被提醒後沒有回覆。
- 退出條件失效。
- 開始改口。
- 第一次真的認錯。

圖表規則：

- 獲利與虧損使用同等視覺重量。
- 不以煙火、金幣、皇冠或紅綠大字慶祝。
- 不預設把最好區間放大。
- 資料缺漏與修正直接畫在時間軸上。
- 不以顏色作為唯一方向或狀態訊號。
- 所有數字使用 tabular figures。

| 用途 | 字體決策 |
| --- | --- |
| 品牌字標 | 為「盤勢・眾生」另畫六字。宋體骨架、碑刻收尾，在部分橫筆留下窄缺口 |

## 圖像生成與角色一致性

ImageGen 產生美術母版，正式狀態決定人物是誰。圖像模型不能發明年齡、職業、關係、持股與當下事件。

每位居民保存：

- 結構化角色 brief。
- 正向與負向 prompt。
- 生成模型與版本。
- seed 或可重現來源記錄。
- 核准日期、用途與核准人。
- 4:5 主肖像、1:1 頭像、9:16 影片安全裁切。
- alt text。

引介資產包另保存 `asset_pack_id`、character／origin ref、identity digest、各 layer hash、atlas budget、rights scope、qualification result 與 approved static fallback。只有肖像、頭像、安全裁切、八層世界 rig、必要表情／姿勢、alt text、identity consistency、成人辨識與中階手機 budget 全部通過，角色才可進公共世界。

Capacity、timeout 或生成失敗只重試同一個 origin／visual seed，不替換成另一張臉。資產尚未就緒時，UI 顯示可恢復狀態，不把灰色人形、半成品或陌生 placeholder 當成角色第一次出場。

正式人物拆成至少八層：

1. 後景。
2. 軀幹與衣物。
3. 頭髮前後層。
4. 臉與膚色。
5. 眼睛。
6. 嘴與眉。
7. 雙手與常用物件。
8. 前景與象徵光紋。

動態由前端或動畫 rig 控制，不在每一幀重新生成角色。換服裝、換場景與長期疲憊狀態必須通過身份一致性檢查。

## 動態

### 世界呼吸

使用 `motion.world_breath`。窗光、紙張、遠景交通與室內物件輕微變化。角色沒有事件時不做誇張 idle。

### 人物微動作

每個動作由正式狀態觸發，不隨機播放。眼神先移動，接著是手、身體重心和與他人的距離。文字最後出現。

### 市場落地

新事實以冷色訊號從來源進入場景，時間使用 `motion.market_signal_in_max`。不能用光量、粒子或震動強度暗示好壞。

### 跟拍

鏡頭依 `camera.follow_in` 靠近。人物身份、空間與聲音方向保持穩定。跟拍交接不顯示成功煙火。

### 走進人生

角色近景向肖像過渡，場景物件摺成一頁人生誌。完整過場使用 `transition.enter_journal`；可在中途取消，也不能遮住資料狀態。

### 說法對照

原話與現在說法以同一位置換頁，不用紅叉批改。兩句各自顯示時間與 artifact ref；換行、字幕、分享與無障礙文字不能改寫。使用者先看到文字變化，再展開造成變化的事件。

### Reduced motion

取消縮放、景深、視差、漂移與星軌。替代淡入、描邊與狀態文字不得超過 `motion.reduced_fade_max`。所有功能仍可完成。

## 音效

聲音由空間、物件與人物構成：

- 紙張、鍵盤、手機震動、腳步、雨聲與遠處交通。
- 角色呼吸、停頓與語尾變化只使用已核准 `VoiceIdentityProfileV1`；不能因某句生成失敗臨時換一個聲線。
- 低頻市場脈衝只標示事件抵達，不標示漲跌。
- 一名角色固定一組細小聲音習慣，例如轉筆、敲桌、拉椅或關抽屜。

可聽台詞只播放引用同一 `UtteranceArtifactV1` text hash 的 `UtteranceAudioRenditionV1`。字幕逐字取 canonical text，時間 cue 只對齊、不重寫；音訊失敗時回到完整文字與字幕，人物動作仍可成立。

禁止賭場提示音、報酬慶祝音、硬幣聲與恐嚇式倒數。

## 響應式與可及性

- 所有點擊區至少 44 × 44 pt。
- 正文可放大至 200%，不得遮住姓名、狀態與下一動作。
- 關係圖在手機預設改成排序列表；使用者主動切換才顯示縮小星圖。
- 圖表提供等價資料表與事件摘要。
- 螢幕閱讀器先讀人物、動作、事件，再讀數字。
- 不能只靠顏色、位置、聲音或動態表達狀態。
- 角色對外說法、內心自覺與系統觀察者文字有不同語意標籤。

## 禁用語法

- 公共首頁滿版 K 線、行情跑馬燈、全員資產表。
- 黑金券商終端、賭場紅綠、金幣、寶箱、轉盤與連勝火焰。
- 霓虹 AI 漸層、玻璃卡與沒有資料意義的粒子。
- 通用抽卡立繪、幼齒 chibi、同一張漂亮臉換髮型。
- 每個面板等寬等高，每段內容都像後台元件。
- 把星座符號貼在臉上，或把命盤線連到價格方向。
- 只做一張角色大圖，靠文字宣稱他正在焦慮或後悔。
- 用「AI 正在深度思考」掩蓋等待、失敗或資料缺漏。
